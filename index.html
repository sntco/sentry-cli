SENTRY · DEVELOPER PREVIEW

Vault credentials.
Your command line.

The separate sentry CLI lets local commands use selected vault fields after approval in Sentry.

Development preview. Apple silicon and macOS 27 or later. Requires the matching Sentry development app; the production App Store connection is still being qualified. The CLI is ad-hoc signed and not notarized.

Install a preview

Choose a version from preview releases. No Swift, Xcode or administrator password is needed to install the CLI. Replace VERSION below with the release number.

installer=$(mktemp)
curl --proto '=https' --tlsv1.2 -fsSL https://sntco.github.io/sentry-cli/install.sh -o "$installer"
# Review the downloaded script, then:
bash "$installer" VERSION

Or, after reviewing and trusting the installer:

curl --proto '=https' --tlsv1.2 -fsSL https://sntco.github.io/sentry-cli/install.sh | bash -s -- VERSION

The CLI is linked at ~/.local/bin/sentry. Add that directory to your shell's PATH if needed:

export PATH="$HOME/.local/bin:$PATH"
sentry --version
sentry --help

Make the PATH change persistent in your shell configuration if desired. The installer does not edit it.

Use a saved field

sentry run --env 'API_TOKEN=vault://Hosting%20account/password' -- /absolute/path/to/command
sentry access list
sentry access revoke 'Hosting account'

Use the exact, unique saved item title, percent-encoded in field references. Open Sentry and unlock normally, then choose Allow once, Allow always or Deny. Allow always covers the entire item for any local program while Sentry is unlocked. Commands can expose credentials they receive; check their behavior and output.

Update or uninstall

Run the installer with the newer preview version to update. It verifies the download and switches the CLI link without stopping running commands. Previous versions are retained until uninstall. There is no background updater yet.

bash "$installer" NEW_VERSION
bash "$installer" --uninstall

Uninstall removes only verified preview installations. It preserves the app, vault, shell configuration and unrelated commands. An interrupted install can leave a lock; inspect it and confirm no installer is running before removing that lock.

What is verified?

Each release includes the executable, SHA-256 checksum and source/toolchain/protocol manifest. The installer checks the checksum, ad-hoc signature and architecture before installing. HTTPS and checksums from the same release protect delivery integrity; they do not independently authenticate Sentry as publisher. Ad-hoc signing is not Developer ID signing.

If macOS blocks execution, stop and report the result. The installer does not remove quarantine or disable Gatekeeper. Developer ID signing and notarization are planned before production launch. Keep the app and CLI on the same current protocol; older prototype formats are refused.
